# 美容室アプリ(カスタマイズ可能テンプレート)

美容室向けのホームページ + 予約受付 + 管理画面のプロトタイプです。
**基本機能はテンプレートとして用意し、店舗ごとの違い(写真・配置・文言・メニュー・色)は管理画面から一元管理してカスタマイズする**という構成になっています。

依存ライブラリ・ビルド不要。ブラウザで HTML を開くだけで動きます。

## 構成

```
beauty-salon-app/
├── index.html          # 顧客向けサイト(設定から動的に描画)
├── admin.html          # 管理画面(オーナー向け・一元管理)
├── assets/
│   ├── js/
│   │   ├── config.js   # 設定スキーマ + 保存/読込/入出力API(共通レイヤー)
│   │   ├── site.js     # サイトの描画ロジック
│   │   └── admin.js    # 管理画面のロジック
│   └── css/
│       ├── site.css
│       └── admin.css
└── README.md
```

## 使い方

1. `admin.html` をブラウザで開く
2. 各タブで店舗情報・写真・メニューなどを編集し「保存」
3. `index.html`(または管理画面の「サイトを開く」)で仕上がりを確認

## 管理画面でできること(一元管理)

| タブ | 内容 |
|---|---|
| 基本情報 | 店名・キャッチコピー・紹介文 |
| デザイン | テーマカラー4色・書体(明朝/ゴシック) |
| 配置 | セクションの表示順の並び替え・表示/非表示・見出し文言 |
| 写真 | メイン画像・コンセプト画像・ギャラリーのアップロード(自動リサイズ) |
| メニュー | カテゴリ/項目の追加・料金・所要時間 |
| スタッフ | プロフィール・写真・並び順 |
| お知らせ | 日付つきのお知らせ管理 |
| アクセス・営業時間 | 住所・電話・営業時間・地図埋め込み |
| 予約設定 | フォーム予約の有効化・LINE/ホットペッパー導線・SNSリンク |
| 予約一覧 | フォームから入った予約の確認・確定/キャンセル |
| 書き出し・読み込み | 設定JSONのエクスポート/インポート・初期化 |

## カスタマイズの仕組み

- カスタマイズ可能な項目はすべて `assets/js/config.js` の `DEFAULT_CONFIG` に定義されています(= 項目の全一覧)。
- 管理画面での変更は `localStorage` に保存され、**デフォルト設定に上書きマージ**されてサイトに反映されます。
- 「設定の書き出し」で店舗ごとの設定を JSON ファイルとして持ち出せるので、**同じテンプレートを複数店舗に展開**できます(店舗ごとに JSON を読み込むだけ)。

## プロトタイプとしての割り切り(本番導入時の差し替えポイント)

- **保存先が localStorage**: 同じブラウザ内でのみ共有されます。本番では `config.js` の `SalonConfig` / `SalonBookings` の中身を API 呼び出しに差し替える想定です(呼び出し側のインターフェースはそのまま使えます)。
- **予約はフォーム受付のみ**: 空き枠管理・重複チェック・通知(メール/LINE)はバックエンド導入時に追加。
- **認証なし**: `admin.html` は誰でも開けるため、公開時は管理画面側に認証を付ける必要があります。
